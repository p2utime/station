05

FAQ

드래그해도 버튼이 안 떠요

먼저 켜 둔 사이트인지 확인해 주세요. 확장 아이콘을 누르면 지금 사이트의 상태가 보이고, 꺼져 있다면 이 사이트에서 켜기를 누르면 됩니다. 켜져 있는데도 안 뜬다면, 설치 전부터 열려 있던 페이지는 새로고침이 필요합니다. 이외에도 드래그/복사를 막아 둔 사이트, 브라우저 설정 화면, 구글 문서처럼 글자를 고를 수 없는 곳에서는 버튼이 뜨지 않습니다. 이럴 땐 우클릭 → 발췌기로 발췌나 단축키 Alt + Shift + Y를 써 보세요.

발췌기 탭을 꼭 열어둬야 하나요?

발췌기 탭이 열려 있지 않아도 버튼을 누르면 발췌기를 자동으로 연 뒤 글을 넣어 줍니다. "이전 작업 복원" 창이 뜬 이후 글이 들어가니 선택 버튼을 꼭 눌러 주세요.

"개발자 모드 확장 프로그램" 경고가 떠요

스토어를 거치지 않고 직접 설치한 확장이라 브라우저가 보여 주는 안내입니다. 이 확장은 그대로 써도 괜찮습니다.

드래그한 글이 어딘가로 전송되나요?

드래그한 글은 내 브라우저 안의 발췌기 탭으로만 옮겨지고, 외부 서버로는 아무것도 수집하지 않습니다.

폰에서도 쓸 수 있나요?

모바일 크롬·웨일은 확장프로그램을 지원하지 않아서, 지금은 PC에서만 사용 가능합니다.

설정은 어디서 바꾸나요?

툴바의 확장 아이콘을 누르고 설정 · 사이트 관리를 누르거나, 아이콘 우클릭 → 옵션을 누르면 됩니다. 사이트 목록, 버튼 띄우기, 발췌기 탭으로 자동 이동, 채팅 번호 버튼 개수 같은 설정을 바꿀 수 있습니다.

사이트를 추가할 때 권한을 물어봐요

확장프로그램은 허락받은 사이트에서만 동작할 수 있어서, 새 사이트를 추가할 때마다 브라우저가 한 번 묻습니다. 허용을 눌러야 그 사이트에서 버튼이 노출됩니다. 목록에서 빼면 권한도 함께 돌려줍니다.

우클릭·단축키는 설정이 꺼진 사이트에서도 되나요?

네! 우클릭 → 새 발췌 / 이어 붙이기와 단축키 Alt + Shift + Y는 사이트 목록과 상관없이 어디서나 쓸 수 있습니다.
